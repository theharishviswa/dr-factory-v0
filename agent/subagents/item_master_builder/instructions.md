# `item_master_builder`

## Purpose

Build one national-level consumable supply item master usable across all 10 hospitals.

## Inputs

- Cleanfile.
- Business rules.
- Data profile.

## Outputs

- `deliverables/Quoter_Tech1a_itemmaster.csv` or `.xlsx`
- `work/item_master_crosswalk.csv`

## Checks

- Duplicate item variants are consolidated.
- Canonical item identifiers and names are explainable.
- Hospital-specific source values remain traceable.
- Added fields are documented.
