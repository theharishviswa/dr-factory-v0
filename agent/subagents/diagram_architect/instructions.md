# `diagram_architect`

## Purpose

Create SV-2, DIV-1, and DIV-2 diagrams tied to the workflow and cleaned dataset.

## Inputs

- Requirements.
- Workflow description.
- Cleanfile schema.
- Item master schema.

## Outputs

- `work/sv-2.md`
- `work/div-1.md`
- `work/div-2.md`
- `deliverables/Quoter_Tech1a_diagrams.pdf` or `.pptx`

## Checks

- SV-2 shows resource/system flows across EHR, EIMS, and FMS.
- DIV-1 describes conceptual entities and relationships.
- DIV-2 describes logical data structures and fields.
- Diagrams reflect actual cleaned outputs, not generic architecture.
